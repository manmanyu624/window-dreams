# 零件

设计说明里最容易写歪的几块，这里有我们家在用的样子。每个文件单独能用，互相不依赖，只用 Python 自带的库。

零件是给照着说明自己搭的人抄的。白天那一半（梦簿怎么存、每一轮怎么把想起来的句子递给他）我们家的整套实现在 [`../白天那一半/`](../白天那一半/)；夜里怎么起、怎么做出一个梦，跟每家的环境绑得很紧，见设计说明第八节末尾和第九节。

|---|---|---|
| `lock.py` | 一句一句上锁、开锁。钥匙可以放环境变量、一个只有自己能读的文件，或 macOS 钥匙串 | 第五节、第九节 |
| `shatter.py` | 把今晚的料打成歪的碎片 | 第一节 |

| `embed.py` | 两句话意思像不像 | 第三节 |
| `test_parts.py` | 上面几样的测试。不调模型，文字全是编的 | |

```
python3 test_parts.py
```

## 用之前要知道的

- **模型**。`shatter.py`、`shadow.py`、`embed.py` 默认找本机的 ollama（`qwen3:8b` 和 `bge-m3`）。地址和模型名可以用环境变量 `DREAM_OLLAMA`、`DREAM_SMALL_MODEL`、`DREAM_EMBED_MODEL` 换；要换成别家的接口，改各文件里的 `_ask()` 或 `embed()` 那几行。换成调外面的接口，梦和她说的话就会离开你的机器，取舍见说明第九节。
- **钥匙**。`lock.py` 先看环境变量 `DREAM_KEY`，再看 `DREAM_KEY_FILE` 指的文件，最后才用 macOS 钥匙串。不在 Mac 上的，设前两样里的一样。
- **数**。`wake.py` 那张表、`shadow.py` 里的字数范围，都是在我们家过出来的。你们的作息、用的模型不一样，照抄多半不合适，自己过几天再调。
- **提示词是中文的**。他要是不说中文，`shatter.py` 和 `shadow.py` 的提示词和把关（按字数算的那些）都得重写。
